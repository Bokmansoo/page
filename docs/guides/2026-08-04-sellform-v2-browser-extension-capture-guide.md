# Sellform 브라우저 상품 자료 수집 사용 안내

이 기능은 1688, 타오바오·티몰, 샤오홍슈, 쿠팡, 스마트스토어 등에서 판매자가 **직접 열어 둔 현재 상품 탭**의 선택 자료를 Sellform 프로젝트에 참고용으로 보내는 기능입니다.

## 하기 전 준비

백엔드와 프론트엔드를 실행합니다.

```powershell
Set-Location C:\page
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\run_backend.ps1
```

새 PowerShell 창에서 실행합니다.

```powershell
Set-Location C:\page\frontend
npm.cmd run dev
```

## 확장 프로그램 설치와 연결

1. Chrome 주소창에 `chrome://extensions`를 입력합니다.
2. 오른쪽 위의 **개발자 모드**를 켭니다.
3. **압축해제된 확장 프로그램을 로드합니다**를 눌러 `C:\page\browser-extension` 폴더를 선택합니다.
4. Sellform에서 `http://localhost:3000/workspace/browser-capture`로 이동합니다.
5. **연결 코드 만들기**를 누르고 표시된 일회용 코드를 복사합니다. 코드는 10분 안에 한 번만 사용할 수 있습니다.
6. 브라우저 툴바의 Sellform Product Capture를 열고 코드를 붙여 넣어 연결합니다.

## 자료 보내기

1. 로그인·CAPTCHA를 우회하지 않고, 브라우저에서 일반적으로 볼 수 있는 상품 페이지를 엽니다.
2. 필요한 상품 설명이나 사양만 마우스로 드래그해 선택합니다.
3. 확장 프로그램에서 **현재 탭 캡처**를 누릅니다.
4. 제목·선택 텍스트·후보 이미지와 대상 프로젝트를 확인합니다.
5. 최종적으로 참고할 이미지에만 체크한 뒤 **프로젝트로 전송**을 누릅니다.

전송된 원문·이미지 URL은 공급처 자료이므로 `reference_only` 상태입니다. 사실·증거 보드에서 수치와 표현을 확인한 뒤에만 상세페이지 문구에 사용하세요.

## 제한과 안전 원칙

- 403, 로그인 제한, CAPTCHA, 유료벽을 우회하지 않습니다. 필요한 자료는 판매자가 직접 캡처하거나 업로드합니다.
- 확장 프로그램 권한은 `activeTab`, `scripting`, `storage`뿐입니다. 모든 사이트를 백그라운드로 읽는 권한은 사용하지 않습니다.
- 쿠키, 세션, 비밀번호, 결제·주문·회원 정보는 보낼 수 없으며 발견되면 API가 차단합니다.
- 연결은 같은 워크스페이스의 프로젝트에만 전송할 수 있습니다. 더 이상 쓰지 않는 연결은 Sellform의 **내 연결 관리**에서 해제하세요.
