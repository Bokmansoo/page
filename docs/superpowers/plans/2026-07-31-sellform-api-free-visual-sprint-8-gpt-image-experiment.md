# Sellform Sprint 8 선택적 GPT 이미지 보강 실험 실행계획

**상위 기획:** [이미지 API 없는 상품 비주얼 자동 조합 기획](../specs/2026-07-31-sellform-api-free-product-visual-composition-design.md)  
**목표:** 기본 자동 조합을 유지하면서 GPT 이미지 API가 가치 있는 구간과 비용·위험을 검증한다.  
**기간:** 1주  
**의존성:** Sprint 7의 기본 품질 기준 통과, 명시적 API 비용 승인

## 범위

- 실제 상품 사진 기반 선택적 이미지 편집 실험
- 배경 확장, 분위기 연출과 보조 장면 후보
- API 미사용 결과와 블라인드 비교
- 상품 정체성·비용·시간·실패율 측정
- 기능 채택 여부 결정

## 제외

- 모든 섹션의 강제 API 생성
- GPT 이미지에 한글 문구·스펙 표 렌더링 맡기기
- API 실패 시 기본 상세페이지 생성 차단
- 승인 없는 실제 유료 호출

## 예상 수정 파일

- `backend/src/services/image_generation_provider.py`
- `backend/src/services/image_generation_service.py`
- `backend/src/config.py`
- 이미지 비용 승인 API와 UI
- 후보 선택·거절 UI
- `.env.example`
- 관련 provider contract 테스트

## 실험군

| 군 | 구성 |
| --- | --- |
| A | 실제 상품 사진 + HTML/CSS/SVG 자동 조합 |
| B | 실제 상품 사진 + GPT 배경 편집 + HTML/CSS 텍스트 |
| C | GPT 보조 장면 후보 + 실제 상품 중심 HERO + HTML/CSS 텍스트 |

## 작업

### Task 1: 실험 계약과 안전장치

- [ ] API 호출이 기본값으로 꺼져 있는지 확인한다.
- [ ] 비용 승인, 최대 후보 수와 재시도 한도를 설정한다.
- [ ] 원본 상품 사진을 항상 보존한다.
- [ ] API 실패 시 Sprint 7 결과로 fallback한다.

### Task 2: 제한된 사용 사례

- [ ] 텍스트가 없는 배경 확장 후보를 생성한다.
- [ ] 상품 본체가 아닌 분위기용 보조 배경을 생성한다.
- [ ] 실제 상품 사진을 입력으로 전달하는 편집 흐름을 검증한다.
- [ ] 모든 한글, 수치와 CTA는 HTML/CSS로 유지한다.

### Task 3: 품질 및 정체성 검사

- [ ] 제품 형태, 색상, 로고와 구성품 변형 여부를 검수한다.
- [ ] 변형이 감지된 후보는 자동 적용하지 않고 거절한다.
- [ ] 판매자가 후보 적용 전 원본과 비교할 수 있게 한다.
- [ ] 동일 프롬프트의 결과 일관성을 기록한다.

### Task 4: 비용·효과 평가

- [ ] 후보별 비용, 생성 시간, 실패와 재시도 횟수를 기록한다.
- [ ] A/B/C 결과를 상품명 없이 품질 평가한다.
- [ ] 시각 개선, 수정 감소와 구매 콘텐츠 적합성을 비교한다.
- [ ] 기본 기능, 유료 옵션 또는 제외 중 제품 결정을 기록한다.

## 채택 기준

- [ ] API 결과가 대조군보다 반복적으로 높은 평가를 받는다.
- [ ] 상품 정체성 변형률이 허용 기준 이하다.
- [ ] 비용과 대기 시간이 사용자 가치에 비례한다.
- [ ] 실패해도 API 없는 결과가 정상 제공된다.
- [ ] 사용자가 비용 발생 전에 명시적으로 승인한다.

## 최종 결정

실험 종료 시 다음 중 하나를 선택한다.

1. 기본 기능: 품질 향상이 크고 비용·실패가 충분히 낮음
2. 선택적 유료 기능: 특정 배경·연출 컷에서만 가치가 있음
3. 제외: 자동 조합 대비 개선이 작거나 상품 변형 위험이 큼

결정 결과와 근거는 별도의 ADR 또는 리뷰 문서로 남긴다.
