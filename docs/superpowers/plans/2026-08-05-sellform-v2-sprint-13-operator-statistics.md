# Sellform V2 Sprint 13 — 운영자 통계·감사 로그

상태: 구현 계획  
선행 조건: Sprint 12  
후속 Sprint: Sprint 14 공개 템플릿 동의

## 1. 목표

운영자는 서비스 운영에 필요한 집계와 감사 정보만 보고, 개인 사진·상세페이지 본문을 임의로 열람하거나 재사용할 수 없게 한다.

## 2. 허용 데이터

- 전체 사용자·활성 워크스페이스·프로젝트·생성·출력 건수
- 크레딧 사용량과 결제·환불 상태
- 작업 실패율, 오류 코드, 처리 시간, 공급자 상태
- 로그인·권한 변경·다운로드·삭제 등 보안 감사 이벤트

## 3. 금지 데이터

- 고객 사진 원본과 생성 이미지 미리보기
- 상품명, 상세페이지 본문, 사실 카드의 실제 내용
- 다운로드 파일 내용
- OAuth 토큰, 세션 토큰, 결제수단 원문

## 4. 구현 범위

- 별도 운영자 역할과 운영자 인증 경계
- Sprint 10에서 정의한 `platform_admin`은 이 Sprint에서 운영 통계 전용 API와 화면에 연결한다. 이 역할은 고객 콘텐츠를 조회하는 지원자 권한이 아니다.
- 콘텐츠를 제외한 집계 전용 쿼리 또는 테이블
- 운영자 행동 감사 로그와 최소 권한
- 오류 로그의 개인정보·본문·파일 경로 마스킹
- 긴급 지원 접근이 필요할 경우 별도 승인·시간 제한·사용자 통지 정책 수립

## 5. 완료 기준

- 일반 사용자와 운영자 API가 분리된다.
- 운영자 응답에 고객 콘텐츠가 포함되지 않는 자동 테스트가 통과한다.
- 모든 운영자 조회와 변경이 감사 로그에 남는다.
