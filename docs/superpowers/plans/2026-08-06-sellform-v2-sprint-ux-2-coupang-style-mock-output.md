# Sellform V2 Sprint UX-2: 쿠팡형 상세페이지·사진 배치·Mock 출력

상태: 구현 완료  
선행: UX-1

## 목표

이미지 생성 API 없이도 판매자가 올린 사진, 확인된 상품 정보, HTML/CSS 그래픽으로 쿠팡형 세로 상세페이지를 만들고 PNG로 다운로드한다. 공급처 참고 사진과 경쟁사 문구는 최종 출력에 사용하지 않는다.

## 기본 흐름

```text
사진·스펙 입력 → 사진 역할 자동 분류 → 쿠팡형 템플릿 조립 → 결과 검수 → PNG 다운로드
```

## 템플릿

1. 대표 제품 사진(HERO)과 한 줄 가치 제안
2. 고객 상황 공감
3. 확인된 핵심 기능 3개
4. 사용 방법 또는 조작·충전 안내
5. 제품 디테일과 구성품
6. 제품 사양·주의사항·필수 고지(항상 마지막)

## 규칙

- 직접 촬영·사용 허가 사진만 HERO/최종 이미지에 자동 배치한다.
- 사진이 없는 섹션은 빈 이미지 박스가 아닌 HTML 정보 카드·아이콘·도식으로 출력한다.
- 공급처 사진은 AI 생성 참조 또는 고급 편집 참조로만 유지한다.
- 확인 근거가 없는 인증, 안전성, 치료·효능, A/S, 보증 문구를 생성하지 않는다.
- Mock 모드에서도 HERO가 HTML 제품 소개형이면 다운로드를 막지 않는다.

## 완료 기준

- 사진·스펙 입력만으로 쿠팡형 세로 페이지와 마지막 고지 섹션이 생성된다.
- 사진 부족 상태에서 `사진 필요`가 최종 결과·다운로드 파일에 나타나지 않는다.
- 공급처 참고 사진은 최종 파일에 포함되지 않는다.
- Mock 모드 E2E에서 PNG 다운로드가 성공한다.
- 실제 이미지 API 연결 뒤에는 HTML 슬롯을 제품 정체성 검증된 생성 이미지로 교체할 수 있다.
