# Sellform V2 Sprint 2 — 이미지 자산 이해·OCR·번역

상태: 다음 구현 대상  
선행 조건: Sprint 1  
후속 Sprint: Sprint 3 사실·증거 보드

## 1. 목표

업로드된 사진의 역할, 품질, 중복, 언어와 최종 사용 가능 여부를 분석하고 판매자가 결과를 쉽게 수정하게 한다.

## 2. 분류 역할

- 대표 제품컷
- 기능컷
- 사용 장면
- 구성품
- 소재·디테일
- 스펙표
- 포장·배송 정보
- 배너·장식·로고 중심 이미지
- 중복·저화질·상품 식별 불가 이미지

## 3. 분석 범위

### 3.1 시각 분석

- 해상도, 비율, 선명도, 텍스트 점유율
- 대표 상품 식별 가능 여부
- 동일·유사 이미지 해시와 반복 후보
- 로고·워터마크·공급처 디자인 위험 신호
- AI 장면 생성의 정체성 기준 이미지 적합 여부

### 3.2 OCR·번역

- 한국어·중국어·영어 OCR
- 원문과 한국어 번역을 함께 저장
- 숫자·단위·모델명·구성품·주의사항 위치 보존
- 이미지 좌표와 텍스트 블록 연결
- 번역 불확실성 또는 인식 실패 표시

### 3.3 사용 가능 상태

- `reference_only` 공급처 배너는 OCR 근거로 사용하되 최종 자산 후보에서 제외
- `seller_owned` 이미지는 품질 검사를 통과하면 최종 자산 후보 가능
- 로고·권리·저화질 문제가 있으면 `blocked` 또는 `needs_review`
- 역할 변경은 판매자 수정으로 기록하고 이후 자동 분석이 덮어쓰지 않는다.

## 4. 자산 보드 UI

- 썸네일, 파일명, 출처, 권리 상태
- 자동 역할과 판매자 수정 역할
- 품질 경고와 중복 그룹
- OCR 원문·번역·숫자 후보
- 최종 출력 가능, AI 참고 가능, 사용 금지 상태
- 현재 또는 예정된 섹션 사용 위치

## 5. YL-T02 기준 결과

- `1.jpg`: 조작부·Type-C 충전, 참고 전용
- `2.jpg`: 기능·스펙, OCR 근거, 참고 전용
- `3.jpg`: 구조·각도 조절, 참고 전용
- `4.jpg`: 사용 장면, 참고 전용
- `5.jpg`: 소재·디테일, 참고 전용
- `6.jpg`: 온열 기능, OCR 근거, 참고 전용
- 단독 제품컷: 상품 정체성 기준 후보

## 6. API·데이터

- 자산 분석 작업 생성·상태 조회·재시도 API
- 분석 결과에 모델 버전과 처리 시각 저장
- `AssetInspection` 또는 동등 구조에 역할·품질·OCR·권리 판정 저장
- 원본 자산은 변경하지 않고 분석 버전을 별도로 보존
- 분석 실패가 전체 프로젝트 실패로 전파되지 않게 한다.

## 7. 제외 범위

- 사실 최종 확정
- AI 신규 이미지 생성
- 스토리보드 배치
- 공급처 디자인을 지우고 최종 이미지로 사용하는 편집

## 8. 테스트

- YL-T02 여섯 장 역할 분류 회귀 테스트
- 중국어 OCR에서 `2000mAh`, `8W`, `10分钟`, `42°C`, `TYPE-C` 보존
- 동일 이미지 중복 탐지와 자동 반복 방지
- 저화질 HERO와 텍스트 과다 배너 경고
- `reference_only` 최종 출력 후보 제외
- 판매자 역할 수정 보존

## 9. 완료 기준

- 기준 상품에서 HERO·기능·사용·소재·스펙 역할을 구분한다.
- OCR 원문과 번역이 자산 좌표에 연결된다.
- 권리 상태와 품질 상태가 최종 사용 가능 여부에 반영된다.
- 같은 사진이 여러 본문 섹션에 자동 반복 배치되지 않는다.

## 10. Sprint 3 진입 조건

각 자산의 역할, 권리, OCR 원문, 최종 사용 가능 여부 중 하나라도 유실되면 사실 추출을 시작하지 않는다.
