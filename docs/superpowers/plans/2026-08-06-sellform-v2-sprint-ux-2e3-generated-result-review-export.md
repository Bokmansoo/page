# Sellform V2 Sprint UX-2E-3: 생성 결과 반영·검수·출력

상태: 기획 완료 · UX-2E-1/2 완료 후 진행  
선행: UX-2E-0, UX-2E-1, UX-2E-2

## 1. 목적

승인된 LLM 카피와 생성 이미지를 상세페이지의 올바른 장면에 반영한다. 중국어 공급처 이미지와 반복된 사양 이미지를 최종 출력에서 제거하고, 생성 실패 장면은 안전한 원본 사진 또는 한국어 정보형 섹션으로 대체한다.

## 2. 결과 흐름

```text
생성 결과 검수
  → 장면별 승인/다른 결과 선택/정보형 전환
  → 상세페이지 섹션 교체
  → 전체 중복·외국어·사실·순서 검사
  → 판매자 최종 승인
  → 동일 버전 미리보기/JPG/분할 ZIP 출력
```

## 3. 섹션 반영 규칙

- HERO에는 승인된 대표 생성 이미지 또는 안전한 제품 원본 사진 하나만 사용한다.
- 사용 장면·전원/충전·기능 장면은 서로 다른 승인 이미지 또는 서로 다른 정보형 레이아웃을 사용한다.
- 중국어·가격·공급처·QR·타사 문구가 보이는 원본은 최종 출력에 직접 쓰지 않는다.
- 제품 크기, 배터리, 전원, 사용 시간, 주의사항은 UX-2E-1에서 확정한 사실로 만든 한국어 HTML 카드/표가 기본이다.
- 비교 섹션은 판매자 승인 비교 근거가 없으면 자사 사양 확인 섹션으로 바꾼다.
- 최종 제품 사양·필수 고지는 항상 마지막 섹션에 둔다.

## 4. 검수와 버전

- 장면별로 `승인`, `다른 결과 선택`, `안전한 원본 사진 사용`, `정보형 전환`, `재생성 요청`을 제공한다.
- 전체 페이지에서 이미지 중복, 외국어/가격/QR, 사실 연결, 누락 섹션, 사양 마지막 규칙을 검사한다.
- 판매자 최종 승인 전에는 출력물을 `판매용 초안`으로 표시한다.
- 승인 시 `DetailPageVersion`에 섹션·사실·생성 작업 ID·원본 기준 사진·검수 결과·채널 프리셋을 동결한다.
- JPG와 분할 ZIP은 같은 최종 버전만 렌더링하고, ZIP에는 버전/생성 계획/검수 결과 매니페스트를 동봉한다.

## 5. 구현 작업

### 백엔드

1. 승인된 `GenerationJob` 결과만 `PageSection.image_asset_id`/문구 후보에 연결하는 서비스와 API를 만든다.
2. 장면별 대체 규칙을 렌더러에 적용해 실패·미승인 생성 결과가 빈 영역이나 가짜 이미지가 되지 않게 한다.
3. 최종화 시 페이지·자산·카피·사실·검수 결과의 해시와 관계를 버전에 저장한다.
4. 내보내기 전 전체 품질 게이트를 실행하고, 통과한 버전의 JPG/ZIP만 만든다.

### 프런트엔드

1. 결과 화면에서 장면별 생성 후보 비교와 승인/대체/재생성 작업을 제공한다.
2. 반복된 이미지와 위험 원본은 왜 제외됐는지 보여 준다.
3. 다운로드 영역에 `실제 AI 생성본 포함`, `정보형 대체 포함`, `판매자 최종 승인 여부`를 표시한다.
4. 다운로드한 ZIP의 매니페스트 구성과 버전 ID를 출력 이력에서 확인할 수 있게 한다.

## 6. 테스트

- 중국어 사양·공급처 이미지가 있어도 최종 페이지에는 한국어 정보형 카드 또는 승인 생성 이미지가 들어가는지 검증한다.
- 같은 원본/생성 이미지를 여러 섹션에 쓰려 하면 대체 또는 검수 경고가 발생하는지 검증한다.
- 생성 실패/판매자 거절 시 기존 안전한 초안이 유지되는지 검증한다.
- 미리보기, 최종본, JPG, 분할 ZIP의 섹션·문구·이미지·생성 계획 해시가 같은지 검증한다.
- YL-T02와 생활용품/뷰티 기준 상품에서 각기 다른 장면 계획과 품질 게이트를 통과하는지 검증한다.

## 7. 완료 조건

- 현재 Mock에서 보였던 중국어 노출·동일 사진 반복·장면과 무관한 사양 사진 문제가 최종 승인본에서 제거된다.
- 실제 생성 여부와 정보형 대체 여부를 판매자와 다운로드 사용자가 명확히 구분할 수 있다.
- 판매자 승인된 하나의 버전이 미리보기와 JPG/ZIP에 동일하게 재현된다.
