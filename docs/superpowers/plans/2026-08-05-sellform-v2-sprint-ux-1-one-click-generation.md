# Sellform V2 Sprint UX-1 — 원클릭 자동 상세페이지 생성

상태: 구현 계획  
선행 조건: Sprint 9  
병행 조건: Sprint 10 데이터 격리 보안 보완  
후속 Sprint: Sprint 10~18 기존 운영·출시 계획

## 1. 목표

판매자가 제품 사진·링크·기본 정보를 입력한 뒤 `상세페이지 자동 만들기` 한 번으로 상세페이지 초안을 받게 한다. 기존 Sprint 3~6의 사실 검증, 스토리보드, AI 리디자인, 렌더러를 다시 구현하지 않고 내부 자동 파이프라인으로 연결한다.

## 2. 기본 사용자 흐름

```text
사진·링크·상품 정보 입력
→ AI가 제품 사실과 외형을 분석
→ AI가 스토리보드 1개를 자동 선택
→ AI가 필요한 장면을 생성·검사
→ 상세페이지 초안 자동 조립
→ 결과 미리보기
→ 수정하기 / 다시 만들기 / 다운로드
```

사용자는 정상 흐름에서 사실 카드, 후보 3개, 장면 작업, 장면별 승인 화면을 거치지 않는다.

## 3. 내부 자동 파이프라인

| 기존 기능 | UX-1에서의 역할 |
| --- | --- |
| Sprint 3 사실·증거 보드 | 업로드·링크 자료에서 사실을 추출하고 충돌·누락을 판단한다. |
| Sprint 4 스토리보드 | 후보 중 정책에 맞는 스토리보드 1개를 자동 선택한다. |
| Sprint 5 AI 리디자인 | 기준 사진을 바탕으로 대표·사용·충전·디테일 장면을 생성한다. |
| Sprint 6 커머스 렌더러 | 승인 가능한 장면과 근거 있는 문구를 상세페이지 초안으로 조립한다. |

## 4. 제품 사진·장면 생성 정책

- 최초 업로드한 판매자 보유 제품 사진을 제품 정체성 기준으로 사용한다.
- AI 생성 장면은 제품의 실루엣, 색상, 버튼, 충전 포트, 구성품을 기준 사진과 일치시켜야 한다.
- 기본 장면은 대표 제품컷, 실제 사용 장면, 충전 장면, 버튼·포트·디테일 장면, 구성품·스펙 안내로 계획한다.
- 원본 사진이 부족하면 필요한 사진을 먼저 요청한다. AI가 확인되지 않은 구조·기능·구성품을 만들어 내지 않는다.
- 제품 정체성·금지 문구·원본 공급처 디자인 복제 검사를 통과하지 못한 장면은 자동 재생성하거나 결과에 사용하지 않는다.
- 공급처 사진은 기본적으로 사실·외형 참고용이며, 최종 사용 권한이 확인된 자산만 원본으로 직접 사용할 수 있다.

## 5. 화면 설계

### 5.1 기본 화면

- 입력 화면: 사진, 링크, 상품명, 카테고리, 핵심 장점만 받는다.
- 생성 화면: 현재 단계와 예상 소요만 표시한다.
- 결과 화면: 완성 미리보기와 `수정하기`, `다시 만들기`, `다운로드`를 제공한다.

### 5.2 고급 편집

다음 기능은 결과 화면의 `고급 편집`으로 이동한다.

- 사실 카드·근거·충돌 검토
- 스토리보드 후보와 섹션 순서 변경
- 문구·섹션 직접 편집
- 기준 사진 선택과 장면별 재생성
- 이미지 생성 승인·거부와 버전 복원

## 6. 예외 흐름

자동 진행을 멈추고 사용자 확인을 요구하는 경우는 아래로 제한한다.

- 상품명·카테고리·핵심 사진이 없는 경우
- 스펙·기능 정보가 서로 충돌하는 경우
- 제품 정체성 검사에 반복 실패한 경우
- 법적 고지·필수 스펙이 누락된 경우
- AI 이미지 생성 비용 또는 권한 승인이 필요한 경우

## 7. 구현 작업

- 기존 단계들을 실행·재시도·중단할 수 있는 단일 생성 오케스트레이터 API
- 단계별 상태: 입력 확인, 사실 분석, 장면 계획, 이미지 생성, 검증, 페이지 조립, 결과 준비
- 중간 산출물과 실패 사유를 저장해 새로고침·재시도 후에도 이어서 실행
- 기본 화면에서 기존 계획·스토리보드 경로를 숨기고 고급 편집으로 이동
- 원클릭 재생성은 변경 범위(문구만 / 장면만 / 전체)를 선택 가능하게 함
- 입력 자산이 부족할 때만 필요한 사진을 구체적으로 요청

## 8. 테스트

- 판매자 보유 제품 사진 1~5장만으로 자동 초안 생성
- 대표·사용·충전·디테일 장면이 기준 제품 정체성을 유지하는지 검증
- 공급처 참고 사진이 최종 출력에 무단으로 사용되지 않는지 검증
- 충돌·사진 부족·생성 실패 시 필요한 사용자 질문만 표시되는지 검증
- 새로고침·중단·재시도 시 중복 생성과 중복 비용이 없는지 검증
- 기본 사용자는 고급 스토리보드 화면을 거치지 않고 결과까지 도달하는지 E2E 검증

## 9. 완료 기준

- 사진·기본 정보 입력 후 한 번의 행동으로 결과 미리보기까지 도달한다.
- 정상 케이스에서 사용자에게 중간 기획·장면 승인 단계를 강요하지 않는다.
- 자동 생성 장면은 제품 정체성과 자산 권리 정책을 통과한 결과만 사용한다.
- 결과 화면에서 수정·재생성·다운로드와 고급 편집 진입이 가능하다.

## 10. 제외 범위

- Sprint 10의 파일 격리·객체 저장소 구현
- 유료 크레딧 결제 정책 변경
- 새 이미지 모델 자체 개발
- 공급처 원본 디자인·문구의 자동 재사용
