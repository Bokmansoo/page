# Sellform V2 Sprint 12 — 1인 셀러 비공개 베타 출시

상태: 구현 계획  
선행 조건: Sprint 11  
후속 단계: 공개 베타·가격 및 카테고리 확대

## 1. 목표

소수의 실제 1인 셀러가 자신의 상품으로 전체 흐름을 사용하게 하고, 결과 품질·시간 절약·결제 의사·실패 지점을 측정해 공개 출시 기준을 결정한다.

## 2. 베타 대상

- 쿠팡그로스 또는 쿠팡 마켓플레이스 셀러
- 네이버 스마트스토어 셀러
- 1688 등 해외 소싱 셀러
- 국내 도매 소싱 셀러
- 직접 촬영 자체 상품 셀러

초기에는 5~10명을 초대하고 리빙·생활용품·뷰티를 포함한다.

## 3. 온보딩

- 카카오·네이버·Google 로그인
- 판매 유형 선택: 해외 소싱, 국내 소싱, 자체 상품
- 첫 프로젝트 체크리스트와 예시 사진 안내
- 링크 실패 시 확장 프로그램 또는 업로드 안내
- 사실 확인, AI 장면 승인, 편집, 출력까지 단계별 도움말
- 첫 프로젝트용 체험 크레딧

## 4. 측정 지표

- 가입→첫 프로젝트 생성 전환율
- 입력→사실 승인→스토리보드→출력 단계별 완료율
- 첫 사용 가능한 미리보기까지 걸린 시간
- 판매자가 수정한 사실·이미지·문구·섹션 수
- AI 이미지 승인·재생성·거부율
- 쿠팡·스마트스토어 다운로드 완료율
- 링크 수집·OCR·생성·출력 실패율
- 유료 버전 잠금 해제율과 재다운로드율
- 환불률, 문의 유형, 만족도와 재사용 의사

## 5. 가격 실험

- 무료 미리보기 범위
- 프로젝트·버전 단위 잠금 해제 가격
- AI 이미지 크레딧 단가
- 첫 구매 보너스 또는 체험 크레딧
- 월 구독 필요성은 실제 반복 사용 데이터 후 결정

한 사용자에게 가격을 불명확하게 바꾸지 않고 실험 그룹과 적용 기간을 기록한다.

## 6. 운영 흐름

- 문의·장애·환불 접수 채널
- 프로젝트 ID, 작업 ID, 거래 ID 기반 진단
- 관리자 재시도, 크레딧 환불, 다운로드 복구
- 위험 상품·권리 침해·금지 표현 신고 처리
- 공지, 점검, 제공자 장애 상태 페이지

## 7. 베타 범위 제한

- 지원 카테고리와 금지·제한 상품 명시
- 자동 마켓 등록은 제공하지 않음
- 결과의 판매자 최종 검수 책임 안내
- 확장 프로그램 지원 브라우저와 사이트 변동 가능성 안내

## 8. 테스트·출시 절차

- 신규 계정의 완전한 첫 프로젝트 리허설
- 세 로그인 제공자와 결제 환경 실거래 소액 검증
- 운영자 장애·환불 훈련
- 피드백 수집 동의와 개인정보 처리 확인
- 롤백 가능한 배포와 기능 플래그

## 9. 완료 기준

- 서로 다른 소싱 경로의 실제 사용자가 전체 흐름을 완주한다.
- 반복되는 상위 실패 원인과 개선 우선순위가 데이터로 정리된다.
- 결과를 실제 판매 채널에 사용할 의향과 지불 의사를 확인한다.
- 환불·장애·권리 문제를 운영자가 추적하고 처리할 수 있다.
- 공개 베타 진행·보류 결정 문서를 작성한다.

## 10. 공개 베타 진입 기준

- 핵심 흐름 완료율과 품질 만족도가 사전에 정한 목표를 충족한다.
- 출시 차단 보안·결제·권리 문제가 없다.
- AI와 출력 원가를 포함해 지속 가능한 가격 범위를 확인한다.
