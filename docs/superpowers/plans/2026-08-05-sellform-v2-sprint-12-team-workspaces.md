# Sellform V2 Sprint 12 — 팀 워크스페이스 완성

상태: 구현 계획  
선행 조건: Sprint 11  
후속 Sprint: Sprint 13 운영자 통계

## 1. 목표

사용자가 명시적으로 초대한 팀원만 같은 워크스페이스의 프로젝트를 역할 범위 안에서 함께 사용하게 한다.

## 2. 권한 모델

- `owner`: 소유권, 결제, 멤버와 워크스페이스 관리
- `admin`: 멤버·프로젝트 운영, 소유권 이전 제외
- `editor`: 프로젝트 생성·편집·출력
- `viewer`: 조회만 가능

## 3. 구현 범위

- 초대 발송·재발송·만료·취소·수락
- 워크스페이스 전환과 현재 역할 표시
- 멤버 역할 변경과 제거
- 마지막 owner 보호 및 소유권 이전 절차
- 초대 이메일과 가입 이메일 불일치 방지
- 모든 멤버십 변경의 감사 로그

## 4. 완료 기준

- 초대 전에는 팀 데이터를 볼 수 없고 수락 후에만 접근할 수 있다.
- 역할별 조회·수정·다운로드·멤버 관리 권한 테스트가 통과한다.
- 제거된 멤버의 기존 세션과 확장 프로그램 토큰이 즉시 권한을 잃는다.
