# Sellform V2 Sprint UX-2D-1: 안전한 자동 이미지 배치

상태: 구현 완료 · 회귀 검증 완료  
선행: UX-2D 판매용 콘텐츠 품질 검수  
후속: UX-2E LLM 텍스트·이미지 생성 API 연결

## 목표

판매자 사진이 최종 출력에 자동 배치될 때, OCR에서 외국어·공급처·가격·전화번호·QR 위험이 감지된 사진과 같은 원본의 복사본을 기본값으로 사용하지 않는다. 적합한 깨끗한 사진이 없으면 해당 섹션은 확정 사실 기반 HTML/CSS 정보형으로 렌더링한다.

`사용 확인`은 판매자의 명시적 예외 선택으로만 유지한다. 자동 생성 결과가 이 확인에 의존해 초록 상태가 되는 흐름은 금지한다.

## 사용자 흐름

```text
사진 업로드·OCR/역할 검사
  → 안전한 사진만 자동 후보로 선택
  → 위험 사진 또는 중복 원본은 자동 제외
  → 대체 사진 없음: 한국어 정보형 카드
  → 결과 화면에서 판매자가 필요할 때만 위험 사진을 수동 선택·사용 확인
  → "판매용 초안 준비됨" 또는 "판매자 확인 후 사용" 상태 표시
```

## 범위

### 1. 자동 배치 안전 게이트

- `foreign_text_exposed`, `phone_number_exposed`, `price_exposed`, `qr_code_review`, `market_or_competitor_text`, `supplier_text_exposed` 위험이 있는 asset은 자동 배치에서 제외한다.
- Asset OCR 원문과 최신 검사 OCR 블록 모두를 사용한다.
- 동일 `content_hash`가 있는 원본·보정본·복사본은 자동 배치 그룹에서 하나만 사용한다.
- 수동 선택은 허용하되, 기존 UX-2D의 명시적 확인 절차를 거친다.

### 2. 정보형 자동 대체

- 위험 또는 중복 사진으로 비어 있는 비-HERO 섹션은 연결된 확정 사실로 `html_graphic`을 만든다.
- 연결 사실이 없으면 과장 문구를 만들지 않고 섹션을 숨기거나 판매자 확인 체크리스트로 이동한다.
- HERO에 안전한 대표 사진이 없으면 사진을 억지로 넣지 않고 기존 안전 HERO/상품 사진 요청 상태를 유지한다.
- 자동 대체된 섹션에는 원인 코드와 선택된 정보형 전략을 `visual_payload`와 버전 스냅샷에 보존한다.

### 3. 상태와 해결 동선

- 자동 제외·정보형 전환은 품질 패널에서 권고로 보여 준다.
- 위험 사진을 수동으로 사용 확인한 최종본은 `판매자 확인 후 사용`으로 표시한다.
- 확인 없이 안전한 사진·정보형으로 구성된 최종본만 `판매용 초안 준비됨`으로 표시한다.
- 미리보기, 최종본, JPG, 분할 ZIP은 동일한 선택/대체 결과를 사용한다.

## 완료 조건

- 중국어·가격·전화번호·공급처·QR이 감지된 사진이 새 자동 생성의 기본 JPG에 들어가지 않는다.
- 깨끗한 대체 사진이 없는 기능·사용·사양 섹션은 한국어 정보형 카드로 렌더링된다.
- 동일 해시 복사본이 자동으로 두 섹션에 배치되지 않는다.
- 수동 예외 확인이 있는 경우에만 `판매자 확인 후 사용` 상태가 표시된다.
- 기존 판매자 수동 사진 선택·권한 확인·내보내기 흐름은 유지된다.
- 이미지/LLM 생성 API 비용은 발생하지 않는다.

## 테스트 계획

- OCR 중국어·가격·전화번호·QR·공급처 문구 asset의 자동 제외 단위 테스트
- 동일 해시 원본·복사본 자동 배치 1회 제한 테스트
- 위험 사진만 있는 섹션의 HTML 정보형 대체 및 스냅샷 저장 테스트
- 수동 확인 상태와 일반 판매용 초안 상태 라벨 테스트
- 마사지기 기준 7장 입력 후 JPG/분할 ZIP에 위험 OCR 사진이 자동 포함되지 않는 회귀 테스트
