# Sellform V2 Sprint 1 — 상품 자료 묶음 입력

상태: 기존 구현 보완 계획  
선행 조건: Sprint 0  
후속 Sprint: Sprint 2 자산 이해

## 1. 목표

해외 소싱·국내 소싱·자체 상품을 하나의 입력 흐름에서 받되, 출처와 사용 권리, 모델·옵션, 숫자·단위를 잃지 않는 상품 자료 묶음을 만든다.

## 2. 사용자 결과

- URL을 넣거나 사진과 정보를 직접 올려 프로젝트를 시작한다.
- 링크 수집이 실패해도 업로드와 직접 입력으로 계속 진행한다.
- AI 분석 전에 실제 저장될 정보와 사진 순서를 확인한다.

## 3. 입력 항목

### 3.1 필수 최소 입력

- 상품명 또는 상품 URL
- 상품을 식별할 수 있는 대표 사진 1장
- 판매자가 확실히 아는 핵심 정보 1개 이상

### 3.2 권장 입력

- 상품명, 카테고리, 판매 채널, 모델·옵션
- 대표컷, 정면·측면·후면, 기능, 사용 장면, 구성품, 소재, 스펙 이미지
- 핵심 장점, 구성품, 주의사항, 배송·가격 참고 정보
- 판매자가 직접 입력하는 숫자+단위 사실
- 자산 출처와 권리 상태

## 4. 기능 범위

- 최대 20장 다중 업로드, 드래그앤드롭, 미리보기, 삭제, 순서 변경
- URL 수집 시도 결과와 출처 상태 표시
- 403·로그인·캡차·동적 페이지 실패를 정상 상태로 저장
- `현재 상품 가져오기` 확장 기능은 Sprint 8 이전까지 준비 중 안내
- 판매자 촬영, 사용 허가, 공급처 참고 자료를 구분하는 권리 선택
- 입력 확인 화면에서 원문, 숫자, 단위, 모델·옵션, 사진 순서를 그대로 표시
- 자료 부족 시 필요한 사진 유형을 구체적으로 추천

## 5. 저장 계약

- `ProductProject.intake_snapshot`에 입력 당시 묶음을 불변 스냅샷으로 저장한다.
- `SourceCapture`에 URL, 플랫폼, 수집 상태, 실패 코드, 시각을 저장한다.
- `Asset`에 원본 순서, 출처, 권리 상태, 파일 메타데이터를 저장한다.
- 직접 입력한 사실은 `seller_confirmed` 또는 판매자가 선택한 확인 상태로 저장한다.
- URL 수집 이미지와 직접 업로드 이미지를 중복 없이 병합한다.

## 6. 제외 범위

- 이미지 역할·OCR 분석
- 사이트 접근 제한 우회
- 공급처 자료의 최종 사용 허가 자동 판정
- 브라우저 확장 프로그램 구현

## 7. 테스트

- 해외·국내·자체 상품 세 입력 경로 E2E
- 5장 이상 업로드와 순서 보존
- `260g`, `10분`, `800mAh`, `42°C` 원문 보존
- 다른 워크스페이스 자산 연결 거부
- 403 실패 저장과 직접 업로드 대안 노출
- `reference_only` 기본값과 판매자 권리 선택 저장

## 8. 완료 기준

- 세 입력 경로에서 같은 `ProductProject` 자료 계약을 만든다.
- URL 실패가 프로젝트 중단이 아니라 보완 가능한 상태로 표시된다.
- 판매자가 저장 전 입력 묶음과 권리 상태를 확인할 수 있다.
- 기존 Mock 입력 흐름의 숫자·단위·사진 순서 보존 테스트가 유지된다.

## 9. Sprint 2 진입 조건

입력 이미지의 출처, 권리 상태, 순서, 프로젝트 소유권이 모두 보존되어야 한다.
