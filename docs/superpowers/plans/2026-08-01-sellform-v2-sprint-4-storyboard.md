# Sellform V2 Sprint 4 — 구매 흐름 스토리보드

상태: 구현 계획  
선행 조건: Sprint 3  
후속 Sprint: Sprint 5 AI 리디자인

## 1. 목표

승인된 사실과 사용 가능한 자산을 7~12개 판매 섹션으로 조립하고, 판매자가 이미지 생성과 렌더링 전에 흐름을 확인·수정하게 한다.

## 2. 기본 섹션 순서

1. 문제 또는 사용 상황 공감
2. 제품 정체성을 보여주는 HERO
3. 핵심 구매 이유 요약
4. 핵심 기능 1
5. 핵심 기능 2
6. 핵심 기능 3
7. 사용 장면 또는 사용 방법
8. 소재·구조·디테일
9. 구성품 또는 크기 안내
10. 신뢰·주의·구매 전 확인
11. CTA
12. **최종 제품 스펙 및 고지 정보**

자료가 없으면 선택 섹션을 생략하되 마지막 스펙 섹션은 유지한다.

## 3. 배치 규칙

- `reference_only` 자산은 최종 섹션 이미지로 배치하지 않고 AI 장면 또는 그래픽 참고로만 연결한다.
- `seller_owned`, 승인된 `ai_generated`, `derived_graphic`만 최종 이미지 후보가 된다.
- 동일 자산을 여러 기능 섹션에 자동 반복하지 않는다.
- 섹션 문구는 승인된 사실 ID를 참조한다.
- 이미지가 부족하면 필요한 AI 장면 또는 판매자 업로드를 명시한다.
- CTA 다음에 최종 스펙을 배치하며 다른 섹션이 그 뒤에 오지 않는다.

## 4. 자동 추천

- 상품 카테고리, 고객, 이미지 역할, 사실 수에 따라 2~3개 스토리 후보 제공
- 각 후보에 선택 이유, 필요한 이미지, 위험·누락 항목 표시
- 자료가 충분한 이미지 중심형과 자료가 부족한 정보 그래픽형 구분
- 판매자가 선택하지 않으면 가장 근거가 많은 안전 후보를 기본값으로 사용

## 5. 스토리보드 편집 UI

- 섹션 카드 순서 변경, 숨김, 복원
- 섹션별 사용 사실과 근거 확인
- 이미지 후보, AI 생성 필요, 업로드 필요 상태
- 제목·설명 초안 직접 수정
- 예상 채널 길이와 반복 자산 경고
- 생성 비용 예상치는 Sprint 10 전까지 정보성 값으로만 표시

## 6. 데이터·API

- 스토리보드 버전과 승인된 사실 스냅샷 연결
- 섹션에 역할, 사실 ID, 자산 ID, 장면 요청, 렌더링 템플릿 저장
- 자동 추천 생성·수정·승인 API
- 사실 또는 자산 변경 시 영향받는 스토리보드를 오래된 상태로 표시

## 7. 제외 범위

- 실제 AI 이미지 생성
- 자유 배치 캔버스
- 최종 PNG/JPG 렌더링
- 근거가 없는 판매 문구 보충

## 8. 테스트

- 스펙이 마지막이 아닌 스토리보드 저장 거부
- 동일 자산 반복 경고
- `reference_only` 최종 이미지 배치 거부
- 사실 없는 수치 문구 거부
- 섹션 순서 수정과 버전 복원
- 이미지 부족 시 구체적인 장면 요청 생성

## 9. 완료 기준

- 기준 상품 3종에서 근거 있는 7개 이상 섹션 또는 자료 부족 사유가 만들어진다.
- 판매자가 2회 이하의 교체로 주요 이미지·섹션 흐름을 확정할 수 있다.
- 각 판매 문구와 이미지 요구가 사실·자산 근거에 연결된다.
- 최종 제품 스펙이 항상 마지막이다.

## 10. Sprint 5 진입 조건

HERO, 기능, 사용, 디테일 중 AI 생성이 필요한 장면과 정체성 기준 이미지가 명확히 연결되어야 한다.
