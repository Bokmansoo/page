# Sellform V2 Sprint 8 — 브라우저 보조 상품 수집

상태: 구현 계획  
선행 조건: Sprint 7  
후속 Sprint: Sprint 9 소셜 로그인

## 1. 목표

1688·타오바오·샤오홍슈·쿠팡·스마트스토어 및 유사 사이트가 서버 수집을 차단해도, 사용자가 접근 가능한 페이지에서 명시적으로 선택한 상품 자료를 안전하게 Sellform 프로젝트로 보낸다.

## 2. 사용자 흐름

1. Sellform 웹에서 확장 프로그램 연결 코드를 발급한다.
2. 확장 프로그램에서 코드를 입력해 워크스페이스와 연결한다.
3. 사용자가 상품 페이지를 직접 연다.
4. `현재 상품 가져오기`를 누른다.
5. 상품명·옵션·스펙·이미지 후보를 미리 본다.
6. 제외할 항목과 대상 프로젝트를 선택한다.
7. Sellform으로 전송하고 웹에서 수집 결과를 확인한다.

## 3. 수집 범위

- 현재 URL, 도메인, 페이지 제목, 언어, 수집 시각
- 사용자가 화면에서 볼 수 있는 상품명·옵션·스펙 텍스트
- 사용자가 선택한 이미지와 문서 순서
- 선택한 DOM 영역의 구조화 텍스트 또는 스크린샷
- 출처를 식별할 최소 메타데이터

## 4. 안전·권한 원칙

- 캡차·로그인·유료벽·접근 제어를 우회하지 않는다.
- 페이지 전체를 백그라운드에서 무단 수집하지 않는다.
- 필요한 도메인과 현재 탭에 대한 최소 권한만 요청한다.
- 전송 전에 항상 사용자 미리보기와 확인을 받는다.
- 브라우저 로그인 쿠키와 사이트 인증 토큰을 수집하지 않는다.
- 공급처 자산은 기본 `reference_only`로 저장한다.
- 민감 정보·주문·회원 정보가 감지되면 전송을 차단한다.

## 5. 연결 인증

- 웹에서 짧은 수명의 일회성 연결 코드 발급
- 코드 교환 후 범위·사용자·워크스페이스·기기별 확장 토큰 발급
- 토큰 회전, 만료, 폐기, 전체 기기 로그아웃
- 현재 프로젝트 쓰기 외 권한 금지
- 실제 소셜 로그인 기반 세션 전환은 Sprint 9에서 완성

## 6. 사이트 대응 방식

- 공통 DOM·메타데이터 추출기를 기본으로 사용
- 사이트별 어댑터는 선택자로 실패해도 공통 방식으로 복귀
- 사이트 변경을 원격 규칙 또는 버전 있는 어댑터로 관리
- 추출 실패 시 화면 영역 선택과 스크린샷 업로드 제공

## 7. API·데이터

- 연결 코드 발급·교환·폐기 API
- 수집 미리보기와 최종 전송 API
- `SourceCapture`에 확장 버전, 사이트 어댑터, 선택 범위, 출처 저장
- 파일 크기·개수·MIME·악성 입력 검증
- 중복 URL과 이미지 병합

## 8. 제외 범위

- 사이트 접근 제한 우회
- 구매·주문·장바구니 자동화
- 판매자 계정의 비공개 정보 수집
- 원본 공급처 디자인의 최종 사용 승인

## 9. 테스트

- 1688·쿠팡·스마트스토어 샘플 페이지 어댑터
- 어댑터 실패 후 공통 선택 모드
- 연결 코드 만료·재사용·다른 워크스페이스 전송 거부
- 쿠키와 민감 필드 비수집 검사
- 수집 자산의 `reference_only` 기본값
- 대용량·위조 MIME·악성 HTML 거부

## 10. 완료 기준

- 직접 접근 가능한 기준 페이지에서 사용자가 선택한 텍스트와 이미지를 프로젝트로 보낼 수 있다.
- 403을 우회하지 않고도 직접 업로드보다 빠른 보조 수집 흐름을 제공한다.
- 전송 자료, 출처, 권리 상태, 사용자 승인이 감사 로그에 남는다.
- 사이트 어댑터 실패가 전체 확장 기능 실패로 이어지지 않는다.

## 11. Sprint 9 진입 조건

확장 프로그램 토큰과 웹 Mock 사용자 헤더를 실제 사용자 세션으로 대체할 인증 계약이 준비되어야 한다.
