# Sellform V2 Sprint 11 — 품질·규제·보안 출시 게이트

상태: 구현 계획  
선행 조건: Sprint 10  
후속 Sprint: Sprint 12 베타 출시

## 1. 목표

기준 상품과 공격·실패 시나리오로 전체 서비스를 검증하고, 품질·권리·과장 표현·권한·결제 문제가 남은 상태에서 출시되지 않게 한다.

## 2. 검증 축

### 2.1 상품 사실

- 수치·단위·모델·본체·포장 구분
- 모든 판매 주장과 근거 연결
- 충돌·검토 필요 사실의 자동 사용 금지
- 스펙 마지막 위치와 필수 고지

### 2.2 이미지·디자인

- 공급처 디자인과 카피 미복제
- `reference_only` 최종 출력 미노출
- AI 상품 정체성, 손·인물·사용법 검사
- 반복 이미지, 저화질, 빈 섹션, 잘림 검사

### 2.3 규제·표현

- 의료·치료·질병 예방·효능 보장 표현
- 친환경·저소음·정확한 온도·성능의 근거
- 카테고리별 인증·주의·고지 누락
- 생성 이미지 속 가짜 인증·구성품·기능

### 2.4 인증·권한

- IDOR, 워크스페이스 침범, 자산 URL 추측
- 세션 탈취·고정·CSRF·오픈 리다이렉트
- 확장 토큰 범위와 민감 자료 전송
- 탈퇴·세션 폐기·계정 연결 안전성

### 2.5 결제·운영

- 중복 결제·차감·웹훅 재전송
- 실패 환불과 장시간 처리 중 복구
- 다운로드 권한과 재다운로드
- 외부 AI·OCR·렌더러·결제 제공자 장애

## 3. 기준 상품 회귀

- YL-T02 해외 소싱 리빙 상품
- 생활용품 1종
- 뷰티 1종
- 선택적으로 직접 촬영 자체 상품 1종

각 상품은 입력→분류→사실 승인→스토리보드→AI 리디자인→편집→두 채널 출력→버전 잠금 해제까지 완주한다.

## 4. 자동 품질 게이트

- 필수 사실과 이미지 슬롯 준비 상태
- `reference_only` 노출 검사
- 스펙 마지막 구조 검사
- 미리보기·출력 의미 일치 검사
- 페이지 길이, 파일 크기, 해상도, 이미지 반복
- 위험 문구와 사실 없는 숫자
- 차단 항목이 있으면 유료 다운로드 금지

## 5. 수동 검수

- 판매자 관점 사용성 검수
- 모바일 가독성과 구매 흐름
- 상품 유사도와 사용 장면 자연스러움
- 중국어 흔적·공급처 로고·오역
- CS·환불·장애 대응 절차 리허설

## 6. 관측·운영 준비

- 요청·작업·출력·결제의 상관관계 ID
- 개인정보를 제외한 구조화 로그
- 실패율, 대기 시간, AI 비용, 환불률 대시보드
- 관리자용 작업 재처리와 크레딧 보정 감사 로그
- 장애 알림과 제공자별 차단 스위치

## 7. 테스트

- 백엔드 단위·통합·권한·결제 테스트
- 프론트엔드 lint, 컴포넌트, Playwright E2E
- 기준 상품 이미지 비교와 출력 재결합
- 의도적 제공자 실패·네트워크 지연·중복 요청
- 보안 체크리스트와 비밀정보 노출 검사
- 접근성·키보드·오류 메시지 검사

## 8. 완료 기준

- 출시 차단 등급 결함이 0개다.
- 기준 상품 모두 품질 평가표를 통과한다.
- 공급처 원본 미사용, 사실 근거, 스펙 마지막, 출력 일치가 자동 검사된다.
- 인증·권한·결제 공격 시나리오가 통과한다.
- 장애·환불·문의 대응자가 실행할 운영 문서를 갖는다.

## 9. Sprint 12 진입 조건

출시 승인 체크리스트에 제품·개발·운영 책임자가 모두 승인해야 한다.
