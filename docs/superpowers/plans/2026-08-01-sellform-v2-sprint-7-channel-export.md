# Sellform V2 Sprint 7 — 쿠팡·스마트스토어 출력 일치

상태: 구현 계획  
선행 조건: Sprint 6  
후속 Sprint: Sprint 8 브라우저 확장 수집

## 1. 목표

하나의 마스터 상세페이지를 쿠팡과 스마트스토어용 긴 이미지와 분할 이미지로 변환하고, 미리보기와 다운로드 결과를 동일하게 만든다.

## 2. 결과물

- 웹 최종 미리보기
- 마스터 긴 JPG와 PNG
- 쿠팡 프리셋 긴 이미지·자동 분할 묶음
- 스마트스토어 프리셋 긴 이미지·자동 분할 묶음
- 섹션별 이미지 묶음
- 출력 이력과 같은 버전 재다운로드

## 3. 채널 프리셋

- 폭, 최대 분할 높이, 파일 형식, 품질, 배경 처리, 파일명 규칙
- 프리셋 버전과 적용 날짜 기록
- 공식 규격 변경 시 코드 배포 없이 설정을 교체할 수 있는 구조
- 하나의 마스터에서 내용은 유지하고 크기·분할만 변경

## 4. 출력 흐름

1. 최종 페이지 버전을 고정한다.
2. 이미지·폰트·레이아웃 준비 상태를 검사한다.
3. 출력 전용 렌더 경로를 캡처한다.
4. 긴 이미지를 만들고 안전한 섹션 경계에서 분할한다.
5. 파일 크기·치수·형식·누락을 검사한다.
6. 아티팩트와 프리셋 버전을 저장한다.
7. 브라우저 표준 다운로드로 완료 상태를 표시한다.

## 5. 사용 경험

- PNG/JPG 선택과 예상 처리 시간
- 출력 중 진행 상태와 중복 실행 방지
- 실패 단계와 재시도 버튼
- 브라우저 다운로드 목록에 정상 완료 표시
- 이미 완성된 같은 버전은 즉시 재다운로드

## 6. 데이터·API

- `ExportArtifact`에 페이지 버전, 프리셋 버전, 포맷, 치수, 해시, 상태 저장
- 렌더 요청 멱등성 키
- 실패 원인과 재시도 횟수
- 다운로드 권한 훅은 준비하되 Sprint 10 전에는 무료 개발 모드

## 7. 제외 범위

- 쿠팡·스마트스토어 계정으로 자동 전송
- 결제와 실제 다운로드 잠금
- 채널마다 서로 다른 판매 문구 자동 생성

## 8. 테스트

- 미리보기와 PNG/JPG의 섹션·문구·이미지 해시 비교
- 긴 페이지의 잘림·흰 틈·중복·고정 UI 제거
- 분할 이미지 재결합 시 마스터와 일치
- Playwright 브라우저 다운로드 완료 검증
- 같은 버전 중복 출력 방지와 재다운로드
- Playwright 브라우저 설치 누락의 명확한 사전 점검

## 9. 완료 기준

- 쿠팡·스마트스토어 두 결과를 한 프로젝트에서 받을 수 있다.
- 미리보기와 출력의 의미 있는 시각 차이가 없다.
- 다운로드가 브라우저 완료 기록에 표시된다.
- 출력 실패가 크레딧·결제와 분리된 재시도 가능 상태로 기록된다.

## 10. Sprint 8 진입 조건

외부 수집 방식과 무관하게 직접 업로드 프로젝트가 채널별 출력까지 완주해야 한다.
