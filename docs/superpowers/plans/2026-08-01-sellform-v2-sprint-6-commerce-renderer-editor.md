# Sellform V2 Sprint 6 — 커머스 렌더러·블록 편집기

상태: 구현 계획  
선행 조건: Sprint 5  
후속 Sprint: Sprint 7 채널별 출력

## 1. 목표

승인된 스토리보드와 자산을 쿠팡형 이미지 중심 세로 상세페이지로 렌더링하고, 판매자가 디자인 도구를 배우지 않고 블록 단위로 수정하게 한다.

## 2. 템플릿 시스템

- `commerce_story`를 기본 템플릿으로 사용
- 카테고리·자료량·브랜드에 따른 블록 변형
- HERO, 기능, 사용, 디테일, 구성품, 신뢰, CTA, 최종 스펙 블록
- 검증된 레이아웃 토큰: 폭, 간격, 타이포그래피, 색상, 이미지 비율
- 같은 정보 구조에서 스타일만 바꾸는 템플릿 후보 2~3개

## 3. 블록 편집 기능

- 섹션 순서 변경, 숨김, 복원
- 이미지 교체, 다시 생성, 크롭 위치 조정
- 문구 직접 수정과 근거 기반 AI 수정
- 색상, 폰트, 간격, 정렬 조정
- 사실 근거와 위험 표현 확인
- 변경 전후 비교, 자동 저장, 버전 복원
- 최종 스펙 블록은 내용 수정이 가능하지만 마지막 위치는 고정

## 4. 렌더링 계약

- 미리보기와 출력은 같은 최종 페이지 스냅샷과 렌더러를 사용한다.
- 브라우저 전용 상태, 버튼, 경고, 편집 UI는 출력에서 제외한다.
- 웹폰트와 외부 이미지 로딩 완료 후 캡처한다.
- 고정 폭 마스터를 사용하고 채널 출력에서만 크기와 분할을 변환한다.
- 긴 페이지에서도 이미지 반복, 잘림, 빈 영역, 텍스트 넘침을 검사한다.

## 5. 카피 정책

- 모든 수치·기능 문구는 승인된 사실 ID를 참조한다.
- 근거가 사라지면 해당 문구를 오래된 상태로 표시한다.
- 의료·치료·과장 표현을 안전한 사용 경험 표현으로 순화한다.
- 자동 생성 문구와 판매자 직접 수정 문구를 구분해 기록한다.

## 6. 데이터·API

- 블록 구조, 스타일 토큰, 사실·자산 참조를 포함한 페이지 버전
- 편집 명령의 낙관적 동시성 또는 버전 충돌 처리
- 미리보기용 최종 스냅샷 생성 API
- 렌더러가 DB의 변경 중 상태가 아니라 승인 스냅샷만 사용

## 7. 제외 범위

- 자유 배치 캔버스
- 결제 잠금
- 외부 마켓 자동 등록
- 편집 중 공급처 원본을 최종 이미지로 되돌리는 기능

## 8. 테스트

- 각 블록 유형 렌더링 스냅샷
- 긴 한국어 제목, 단위, 표의 줄바꿈
- 스펙 마지막 위치 고정
- 편집 UI가 출력 HTML에 포함되지 않는지 확인
- 근거 없는 숫자 문구 렌더링 차단
- 버전 저장·복원·충돌 처리
- 기준 상품 데스크톱·모바일 미리보기

## 9. 완료 기준

- 기준 상품 3종이 이미지 중심 판매 흐름으로 렌더링된다.
- 판매자가 핵심 수정 작업을 블록 편집기에서 완료할 수 있다.
- 같은 이미지를 반복하는 임시 레이아웃이 제거된다.
- 미리보기용 스냅샷이 결정적이고 재현 가능하다.

## 10. Sprint 7 진입 조건

편집 화면과 출력 전용 렌더 화면이 동일한 최종 스냅샷에서 같은 섹션 순서와 내용을 보여야 한다.
