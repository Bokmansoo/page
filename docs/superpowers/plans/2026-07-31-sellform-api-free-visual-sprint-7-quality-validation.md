# Sellform Sprint 7 기준 상품 3종 품질 검증 실행계획

**상위 기획:** [이미지 API 없는 상품 비주얼 자동 조합 기획](../specs/2026-07-31-sellform-api-free-product-visual-composition-design.md)  
**목표:** 소형 가전, 뷰티, 생활용품에서 이미지 API 없이 업로드 가능한 결과를 반복 생성한다.  
**기간:** 1주  
**의존성:** Sprint 6 완료

## 범위

- 기준 상품 3종 실사용 검증
- 상품 정체성, 사실성, 가독성과 출력 품질 평가
- 공통 결함 수정
- 생성 시간과 판매자 수정량 측정
- 릴리스 준비 판정

## 산출물

- 상품별 입력 자료와 최종 JPG/PNG
- 상품별 사실 검증표
- 품질 점수표와 수정 기록
- 공통 결함 목록 및 회귀 테스트
- 최종 Go/No-Go 검토 기록

## 평가 기준

| 영역 | 기준 |
| --- | --- |
| 상품 정확성 | 형태, 색상, 로고와 구성품 왜곡 없음 |
| 사실성 | 미확인 수치·효능·정책 노출 없음 |
| 시각 완성도 | 빈칸, 빨간 Mock 이미지와 내부 표식 없음 |
| 가독성 | 모바일과 export에서 제목·표·카드가 읽힘 |
| 편집성 | 이미지 교체 2회 이하, 문구 수정 5회 이하 목표 |
| 출력 | JPG/PNG 다운로드 성공 및 미리보기 일치 |

## 작업

### Task 1: 고정 테스트 팩

- [ ] 상품별 URL, 사진, 스펙, 참고 디자인과 기대 사실을 고정한다.
- [ ] 동일 입력으로 반복 실행할 수 있는 검증 절차를 작성한다.
- [ ] Mock 텍스트와 Real 텍스트 결과를 구분해 기록한다.
- [ ] 생성 전후 서버·브라우저 조건을 동일하게 유지한다.

### Task 2: 품질 실행

- [ ] 소형 가전 결과를 생성·편집·다운로드한다.
- [ ] 뷰티 결과를 생성·편집·다운로드한다.
- [ ] 생활용품 결과를 생성·편집·다운로드한다.
- [ ] 각 단계의 시간, 오류와 수정 횟수를 기록한다.

### Task 3: 결함 수정

- [ ] 세 상품에서 반복되는 공통 결함을 우선한다.
- [ ] 상품별 예외를 범용 규칙과 분리한다.
- [ ] 수정마다 재현 테스트 또는 시각 fixture를 추가한다.
- [ ] 한 상품 개선이 다른 상품을 깨뜨리지 않는지 재검증한다.

### Task 4: 출시 판정

- [ ] 10개 인수 기준을 전부 확인한다.
- [ ] 남은 문제를 blocker, important, polish로 분류한다.
- [ ] blocker가 있으면 Sprint 8로 넘어가지 않는다.
- [ ] 기본 제품의 API 없는 생성 품질을 기준선으로 확정한다.

## 완료 기준

- [ ] 기준 상품 3종 모두 최종 JPG를 생성한다.
- [ ] 상품 정체성 훼손과 근거 없는 판매 표현이 없다.
- [ ] 이미지 누락과 export blocker가 없다.
- [ ] 목표 수정 횟수 안에서 업로드 준비 상태에 도달한다.
