# Sellform V2 Sprint 5 — 상품 정체성 보존 AI 리디자인

상태: 구현 계획  
선행 조건: Sprint 4  
후속 Sprint: Sprint 6 커머스 렌더러

## 1. 목표

공급처 디자인을 복제하지 않고, 승인된 상품 사실과 외형을 근거로 HERO·사용·충전·기능·디테일 장면을 새로 생성한다.

## 2. 사용자 결과

- AI가 필요한 장면을 자동 추천한다.
- 판매자는 간단한 문장으로 배경·인물·분위기를 수정한다.
- 생성 전 상품 기준 이미지와 변경 금지 요소를 확인한다.
- 생성 결과를 사용, 다시 만들기, 수정, 제외할 수 있다.

## 3. 생성 계약

- 입력: 스토리보드 장면 요청, 승인된 사실, 정체성 기준 이미지, 브랜드 키트
- 고정 요소: 제품 실루엣, 색상, 버튼·포트 위치, 주요 구조, 구성품, 로고 정책
- 변경 가능 요소: 배경, 조명, 구도, 소품, 모델, 그래픽 강조
- 출력: 신규 이미지, 프롬프트·모델·비용·시드·입력 자산 이력, 검사 결과

## 4. 장면 유형

- 제품 단독 HERO
- 사람이 제품을 올바르게 사용하는 장면
- 충전·보관·휴대 장면
- 기능 작동 시각화
- 소재·구조 확대
- 구성품 배열
- 크기·규격 정보 그래픽

## 5. 안전장치

- 정체성 기준 사진이 부족하면 측면·후면·조작부 사진을 요청한다.
- 제품에 없는 버튼, 포트, 액세서리, 인증 마크를 금지한다.
- 공급처 원본의 중국어 카피·레이아웃·장식을 재현하지 않는다.
- 얼굴·손·접촉 부위와 실제 사용법을 검사한다.
- 의료·치료·효능을 암시하는 장면과 문구를 제한한다.
- 유사도 또는 사실 검사를 통과하지 못한 결과는 `blocked`로 저장한다.
- `reference_only` 이미지는 모델 참고 입력일 수 있지만 최종 결과에 그대로 합성하지 않는다.

## 6. 생성 작업 상태

- `planned`, `awaiting_approval`, `queued`, `running`, `succeeded`, `failed`, `blocked`, `approved`, `rejected`
- 중복 실행 방지 키와 재시도 횟수
- 외부 제공자 실패와 안전 검사 실패를 구분
- Sprint 10 전에는 비용 예상과 사용량을 기록하되 실제 유료 크레딧은 차감하지 않는다.

## 7. UI·API

- 장면 추천과 프롬프트 요약
- 기준 이미지와 변경 금지 요소 확인
- 생성 비용 예상 및 실행 승인
- 후보 2~3장 비교
- 사용·재생성·간단한 수정·거부
- 생성 작업 API와 비동기 상태 조회
- 승인된 결과를 스토리보드 슬롯에 연결

## 8. 제외 범위

- 자유 배치 디자인 편집
- 결제와 실제 크레딧 차감
- 공급처 사진을 최종 이미지로 자동 대체
- 상품 구조를 창작하는 무근거 이미지 생성

## 9. 테스트

- 정체성 기준 없는 장면 생성 차단
- 제품에 없는 기능을 포함한 프롬프트 거부
- `reference_only` 원본이 최종 자산으로 반환되지 않는지 확인
- 작업 멱등성, 실패·재시도, 승인 상태
- YL-T02 사용·충전·기능 장면의 버튼·형태·구성 검사
- 승인되지 않은 이미지가 렌더러 입력에서 제외되는지 확인

## 10. 완료 기준

- 기준 상품에서 HERO 포함 3종 이상의 서로 다른 신규 장면을 생성·승인할 수 있다.
- 공급처 디자인과 문구가 최종 이미지에 그대로 남지 않는다.
- 상품 정체성 실패 결과가 자동 사용되지 않는다.
- 생성 이력과 비용·모델·입력 근거를 재현할 수 있다.

## 11. Sprint 6 진입 조건

각 필수 이미지 슬롯에 승인 자산, 파생 그래픽 또는 명시적인 안전 대체안이 존재해야 한다.
