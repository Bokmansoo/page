# Sellform V2 Sprint UX-2E-1: OCR·LLM 상품 이해와 한국어 카피

상태: 기획 완료 · API 키/예산 승인 대기  
선행: UX-2E-0 API 연결 준비형 생성 파이프라인  
후속: UX-2E-2 정체성 보존 이미지 생성

## 1. 목적

공급처 이미지에 있는 중국어·영문·숫자 사양을 최종 이미지에 그대로 쓰지 않는다. OCR과 번역은 **사실 후보**를 만들고, 판매자가 확인한 사실만 LLM의 한국어 카피와 이후 이미지 프롬프트에 사용한다.

```text
링크/사진/직접 입력
  → OCR 원문·영역 추출
  → 번역·정규화한 사실 후보
  → 판매자 확인·충돌 해결
  → 확정 사실만 LLM 카피 요청
  → 카피 안전 검사·판매자 승인
```

## 2. 사용자 결과

- 중국어 사양 사진은 `참고 자료`로 남고, 한국어 사양표·카피 후보로 바뀐다.
- 판매자는 원문, 번역문, 근거 사진 영역, 충돌 여부를 보고 사실을 승인/거절한다.
- 장면마다 HERO, 문제 공감, 기능, 전원/배터리, 사용 안내에 맞는 한국어 제목·본문 초안을 받는다.
- LLM이 확인되지 않은 효능, 온도, 비교 우위, 인증, 가격을 쓰면 저장 전에 차단된다.

## 3. 범위

### 3.1 OCR·번역 후보

- 이미지별 OCR 원문, 언어, 신뢰도, 텍스트 영역(bbox), 제공자·모델·처리 시각을 저장한다.
- 번역은 원문과 1:1로 저장하며 자동 확정하지 않는다.
- 숫자·단위·모델명은 원문을 우선 보존하고, `2000mAh`, `8W`, `DC 5V 2A`, `40 × 17 × 15cm`, `10분`처럼 정규화한다.
- OCR 실패·저해상도·외국어 광고 문구는 재시도 또는 판매자 직접 입력 요청으로 표시한다.

### 3.2 사실 근거와 충돌

- 후보는 `ProductFact`/증거 보드에만 추가한다. 기존 판매자 확인 사실을 덮어쓰지 않는다.
- 동일 필드·모델 옵션에 서로 다른 값이 있으면 `conflicted`로 표시한다.
- 의료·치료·수면 개선·경추 보호·친환경·저소음·정확한 온도 같은 표현은 근거가 없으면 `needs_review`로만 저장한다.
- LLM 입력은 `seller_confirmed` 또는 허용된 `source_confirmed` 사실과 판매자 승인 브리프만 사용한다.

### 3.3 LLM 카피

- 입력: 장면 ID, 장면 목적, 승인 브리프, 확정 사실 ID/문장, 금지 표현, 채널, 문체, 최대 길이.
- 출력: 제목, 본문, 근거 사실 ID, 금지 표현 검사 결과, 모델/토큰 사용량, 제공자 응답 ID.
- 카피는 "확인", "안내", "구매 전 확인"처럼 사실 중심으로 작성하며 치료·보장·최고·타사 우월을 쓰지 않는다.
- `comparison` 장면은 판매자가 승인한 비교 기준이 없으면 자사 사양 확인 카피만 만든다.

### 3.4 보안·비용

- OCR/LLM API 키·원본 파일 URL은 백엔드 환경 변수/비공개 저장소에서만 사용한다.
- 브라우저에는 비용 추정, 작업 상태, 승인 가능한 결과만 반환한다.
- 요청마다 `GenerationJob`에 제공자, 모델, 입력 스냅샷 해시, 예상/실제 비용, 오류를 기록한다.
- 실제 요청 전 판매자에게 작업 수·예상 비용을 보여주고 승인받는다. 정식 크레딧 차감은 Sprint 16 원장과 연결한다.

## 4. 구현 작업

### 백엔드

1. OCR·번역 제공자 어댑터와 실패 분류(`provider_error`, `safety_blocked`, `low_confidence`)를 구현한다.
2. OCR 결과를 증거 영역과 함께 사실 후보로 저장하는 서비스/API를 만든다.
3. UX-2E-0의 `GenerationJobRequest/Result`를 LLM 카피 작업에 사용하고 제공자별 응답을 정규화한다.
4. 확정 사실 ID와 금지 표현 검증을 통과한 카피만 `needs_seller_review`로 저장한다.
5. 작업·비용·재시도·감사 로그를 워크스페이스/프로젝트 범위로 저장한다.

### 프런트엔드

1. 외국어/OCR 사진에 `최종 이미지 사용 불가 · 한국어 정보 후보 추출` 상태를 보여 준다.
2. 원문·번역·정규화 값·근거 영역·충돌을 검토하는 사실 후보 화면을 제공한다.
3. 장면별 카피 초안, 사용 근거, 금지 표현 검사, 예상 비용, 승인/재생성 버튼을 제공한다.
4. API 오류·한도 초과·판매자 미승인은 실패 원인과 다음 행동을 명확히 보여 준다.

## 5. 테스트

- YL-T02의 모델·전원·소비전력·배터리·크기·작동 시간을 OCR 후보로 만들되 판매자 승인 전에는 최종 카피에 쓰지 않는지 검증한다.
- 중국어 가격/공급처/광고 문구가 사실 또는 최종 카피로 자동 승격되지 않는지 검증한다.
- 충돌한 마사지 헤드 수와 온열 표현이 `conflicted`/`needs_review`로 남는지 검증한다.
- LLM이 확인되지 않은 치료·보장·비교 우위 표현을 만들면 저장이 차단되는지 검증한다.
- API 키·원본 URL이 브라우저 응답과 로그에 노출되지 않는지 검증한다.

## 6. 완료 조건

- 중국어 공급처 사진의 정보는 판매자 승인 가능한 한국어 사실 후보로 전환된다.
- 최종 카피의 모든 수치·기능·비교 문구가 확정 사실 ID와 연결된다.
- API 실패와 비용 승인 취소는 최종 페이지/다운로드를 변경하지 않는다.
- 승인된 카피만 UX-2E-2 이미지 프롬프트와 UX-2E-3 렌더러에 전달된다.
