# Sellform V2 Sprint UX-2D: 판매용 콘텐츠 품질 고도화

상태: 기획 완료 · 구현 전  
선행: UX-2B API 없는 스펙 기반 한국어 판매 카피, UX-2C 업로드 사진 기반 상세페이지 완성  
후속: UX-2E LLM 텍스트·이미지 생성 API 연결

## 목표

이미지 생성 API와 LLM API 없이도 UX-2C 결과를 단순 Mock 출력이 아닌 **판매자가 검수할 수 있는 판매용 초안**으로 개선한다. 상품명과 파일명을 정상화하고, 섹션별 한국어 문구가 서로 다른 구매 질문에 답하도록 만들며, 같은 사진의 반복 배치와 사진 속 중국어·공급처 문구를 다운로드 전에 발견하고 수정할 수 있게 한다.

이 Sprint는 사진 속 문자를 생성형 AI로 지우거나 새로운 사용 장면을 만들지 않는다. 현재 보유한 사진, OCR 결과, 확정 사실, HTML/CSS 렌더러와 규칙 기반 카피만 사용한다.

## 현재 기준선

마사지기 기준 프로젝트에서 다음 기능은 동작한다.

- 판매자 사진을 HERO와 개별 섹션에 적용할 수 있다.
- 미리보기와 JPG에 선택한 사진이 반영된다.
- 쿠팡 규격 `860px` 긴 이미지와 분할 ZIP을 다운로드할 수 있다.
- 섹션별 이미지 파일과 manifest를 생성한다.

그러나 실제 출력에서 다음 품질 문제가 확인됐다.

- 상품명 대신 전체 스펙 문자열이 프로젝트명과 다운로드 파일명에 들어갈 수 있다.
- `구매 전 제품 정보 확인` 같은 일반 문구가 여러 섹션에 반복된다.
- 사용 안내와 제품 사양에 같은 사진이 중복 배치될 수 있다.
- 중국어 판매 문구가 들어간 공급처 이미지가 최종 JPG에 그대로 노출된다.
- 사진은 배치됐지만 섹션의 제목·본문과 사진 역할이 정확히 맞지 않을 수 있다.

## 사용자 흐름

```text
상품명·스펙 입력
  → 상품명/모델/스펙 분리 확인
  → 규칙 기반 섹션별 한국어 카피 생성
  → 사진 역할·OCR·중복 검사
  → 상세페이지 조립
  → 콘텐츠 품질 검수
  → 문제 섹션 바로 수정
  → 판매용 초안 확정
  → 쿠팡/스마트스토어 JPG·분할 ZIP 다운로드
```

## 범위

### 1. 상품명·프로젝트명·파일명 정상화

- 상품명 필드는 한 줄 상품명만 허용하고 모델명과 상세 스펙을 별도 필드로 유지한다.
- 상품명에 줄바꿈, 여러 개의 `항목: 값`, 과도한 단위 나열이 들어오면 생성 전에 경고한다.
- 프로젝트 표시명은 `상품명` 또는 `상품명 · 모델명`으로 만든다.
- 다운로드 파일명은 정규화된 상품명, 채널, 버전만 사용한다.
- 파일명은 운영체제 금지문자와 연속 공백을 제거하고 확장자를 제외한 길이를 제한한다.
- 정상 상품명이 없으면 무작정 전체 설명을 사용하지 않고 `상세페이지-{project_short_id}`를 사용한다.

권장 예시:

```text
프로젝트명: 경추 마사지 베개 · YL-T02
파일명: 경추-마사지-베개-YL-T02-coupang-detail-2026-08-06.jpg
```

### 2. 섹션 목적 기반 한국어 카피

각 섹션은 하나의 고유한 구매 질문에 답한다.

| 섹션 | 답해야 하는 질문 | 마사지기 예시 |
| --- | --- | --- |
| HERO | 어떤 상품인가? | 목과 어깨에 밀착되는 베개형 마사지기 |
| PAIN POINT | 구매 전 무엇을 고려해야 하나? | 사용 부위와 제품 크기를 먼저 확인하세요 |
| FEATURE 1 | 전원·배터리 정보는? | 2000mAh 배터리 적용 |
| FEATURE 2 | 소비전력과 입력은? | DC 5V 2A 입력 · 정격 소비전력 8W |
| FEATURE 3 | 사용 시간은? | 1회 약 10분 사용 권장 |
| USAGE GUIDE | 어떻게 사용해야 하나? | 사용 전 구성품과 조작 방법을 확인하세요 |
| DETAILS/COMPONENTS | 크기·구성은? | 본체 크기 40 × 17 × 15cm |
| PRODUCT INFORMATION | 최종 확인 정보는? | 모델·색상·전원·크기·포장 정보 |

- 동일하거나 유사한 제목·본문이 두 개 이상 생성되면 중복으로 판정한다.
- 제목은 해당 섹션에 연결된 확정 사실을 우선 사용한다.
- 사실이 부족하면 근거 없는 장점을 만들지 않고 안전한 구매 전 확인 문구를 사용한다.
- `확인된 핵심 정보 1`, `판매자 제공 사양`, 영문 내부 필드명 같은 개발용 문구는 최종 출력에서 금지한다.
- 치료, 통증 완화, 안전 인증, 보증, A/S 등 근거가 필요한 표현은 기존 사실 검증 규칙을 유지한다.

### 3. 사진 역할과 중복 배치 정책

- 사진마다 대표 상품, 조작부, 사용 장면, 온열 기능, 소재, 구성품, 스펙 참고 역할을 유지한다.
- 자동 배치는 섹션의 목적과 사진 역할이 일치할 때만 제안한다.
- 같은 `asset_id`는 기본적으로 하나의 이미지 중심 섹션에만 자동 배치한다.
- HERO 사진을 다른 섹션에 반복 사용하는 대신 사진이 부족한 섹션은 HTML/CSS 사실 카드로 렌더링한다.
- 판매자가 같은 사진을 다시 선택하면 중복 사용 위치와 이유를 보여주고 명시적으로 확인받는다.
- 동일 파일뿐 아니라 파일 해시 또는 중복 판정 그룹이 같은 보정본·복사본도 중복 후보로 취급한다.

### 4. 외국어·공급처 문구 이미지 검수

- 기존 OCR 결과로 한글 외 문자, 공급처 상호, 전화번호, 가격, QR 코드, 경쟁사·마켓 문구를 검사한다.
- 외국어가 검출된 사진에는 이미지 카드와 섹션에 `외국어 문구 확인 필요` 상태를 표시한다.
- 판매자는 다음 중 하나를 선택한다.
  - 외국어가 없는 다른 사진 사용
  - 안전한 범위에서 자르기
  - 해당 섹션을 HTML/CSS 정보형으로 전환
  - 사용 권리와 노출 내용을 확인하고 그대로 사용
- 확인 전에는 경고 상태로 유지하고, 확인자·확인 시각·대상 asset을 페이지 버전에 기록한다.
- 생성형 인페인팅이나 번역 이미지 합성 없이 원본 문자가 제거됐다고 표시하지 않는다.

### 5. 다운로드 전 콘텐츠 품질 검수

결과 화면에 `판매용 품질 확인` 패널을 제공한다.

- 상품명/파일명 이상
- 반복 제목·본문
- 동일 사진 중복 사용
- 섹션 목적과 사진 역할 불일치
- 외국어·공급처 문구 포함 사진
- 근거 없는 판매 표현
- 마지막 제품 사양·주의사항 섹션 누락

각 항목은 `문제`, `확인 필요`, `통과`로 구분하고 해당 섹션으로 바로 이동할 수 있어야 한다. 기술적 내보내기 가능 여부와 콘텐츠 품질 상태를 별도로 표시한다.

- 기술 차단: 이미지 로드 실패, 사용 권한 차단, 최종 사양 섹션 누락
- 판매자 확인 필요: 외국어 노출, 사진 중복, 안전한 자르기 검토
- 품질 권고: 표현 개선, 더 적합한 사진 추천

`판매용 초안` 표시는 기술 차단이 없고 모든 확인 필요 항목을 해결하거나 판매자가 명시적으로 확인한 경우에만 사용한다.

### 6. 미리보기·버전·다운로드 일치

- 품질 검수는 현재 저장된 상세페이지 버전을 대상으로 수행한다.
- 카피, 사진, 중복 허용, 외국어 노출 확인 상태를 버전 스냅샷에 포함한다.
- 미리보기와 쿠팡/스마트스토어 다운로드는 같은 버전과 같은 품질 판정을 사용한다.
- 수정 후에는 이전 품질 결과를 재사용하지 않고 변경된 섹션만 다시 검사한다.
- 기존 다운로드 파일은 자동 변경하지 않으며 수정 후 새 파일을 생성한다.

## 데이터·API 계약

### 계산 또는 저장할 정보

- 정규화된 상품 표시명과 export slug
- 섹션별 `copy_quality_codes`
- 섹션별 선택 asset과 사진 역할 적합도
- 페이지 전체 중복 asset 그룹
- asset별 OCR 언어·노출 위험 코드
- 판매자 확인 항목: 유형, asset/section, 확인자, 확인 시각
- 상세페이지 버전별 콘텐츠 품질 요약

### API 원칙

- 페이지 조회 응답은 섹션별 품질 문제와 수정 가능한 해결 방법을 제공한다.
- 콘텐츠 품질 검사 API는 기술적 export readiness와 별도 결과를 반환한다.
- 사진 선택 API는 중복·외국어 경고를 반환하되, 사용 권한 차단과 판매자 확인 경고를 구분한다.
- export 요청은 확정된 페이지 버전의 품질 상태를 사용하며 다른 프로젝트나 최신 초안의 상태를 섞지 않는다.

## 구현 순서

1. 상품명·프로젝트명·파일명 정규화 규칙과 테스트
2. 섹션 목적별 카피 규칙 및 반복 문구 검사
3. 사진 역할 적합도와 중복 asset 검사
4. OCR 기반 외국어·공급처 문구 위험 코드
5. 결과 화면 `판매용 품질 확인` 패널과 섹션 이동
6. 판매자 확인 상태 저장 및 페이지 버전 포함
7. 쿠팡/스마트스토어 미리보기·JPG·분할 ZIP 회귀 검증

## 완료 조건

- 상품명에 전체 스펙이 잘못 들어오면 생성 전에 경고하고 긴 파일명을 만들지 않는다.
- 마사지기 기준 상품에서 HERO, PAIN POINT, FEATURE 1~3의 제목과 본문이 서로 중복되지 않는다.
- `확인된 핵심 정보 1`, `구매 전 제품 정보 확인` 같은 임시 반복 문구가 최종 JPG에 나타나지 않는다.
- 같은 사진이 두 개 이상의 이미지 중심 섹션에 자동 배치되지 않는다.
- 중국어가 포함된 기준 사진은 다운로드 전에 확인 항목으로 표시된다.
- 외국어 확인 항목에서 다른 사진, 정보형 전환 또는 명시적 사용 확인을 선택할 수 있다.
- 기술적으로 다운로드 가능한 상태와 판매용 품질 통과 상태가 화면에서 구분된다.
- 저장된 미리보기와 JPG, 채널 분할 ZIP의 문구·사진·순서가 일치한다.
- 이미지 생성 API와 LLM API 호출 비용이 발생하지 않는다.

## 테스트 계획

- 상품명·모델명·스펙 분리 및 파일명 길이 단위 테스트
- 섹션별 카피 중복 탐지와 확정 사실 연결 테스트
- 동일 asset/해시 그룹 중복 배치 방지 테스트
- OCR 중국어·전화번호·가격·QR 위험 코드 테스트
- 판매자 확인 상태의 저장·버전 복원 테스트
- 품질 검사와 export readiness 분리 API 테스트
- 마사지기 기준 E2E:
  - 7장 업로드
  - 역할별 자동 배치
  - 반복 문구 없음 확인
  - 중국어 사진 경고 해결 또는 확인
  - 중복 사진 제거
  - 860px JPG 및 분할 ZIP 다운로드

## 명시적 비범위

- LLM을 이용한 자유 카피 생성
- 사람 사용 장면·충전 장면 등 신규 AI 이미지 생성
- 생성형 인페인팅으로 사진 속 중국어 제거
- 원본 상품 외형을 바꾸는 고화질 재생성
- 자유 배치 캔버스 편집기
- 경쟁사·공급처 상세페이지 디자인 복제

## UX-2E 전환 기준

UX-2E의 LLM과 이미지 생성 API는 UX-2D의 사실 연결, 금지 표현, 사진 권한, 중복 배치, 외국어 노출 검수, 버전 고정과 미리보기-다운로드 일치 규칙을 그대로 따라야 한다. API가 만든 문구와 이미지도 같은 품질 패널을 통과해야 하며, API 실패 시 UX-2D 규칙 기반 결과로 안전하게 돌아간다.
