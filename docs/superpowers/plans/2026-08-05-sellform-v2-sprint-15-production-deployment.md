# Sellform V2 Sprint 15 — 운영 배포·저장소·복구 준비

상태: 구현 계획  
선행 조건: Sprint 14  
후속 Sprint: Sprint 16 크레딧·결제

## 1. 목표

로컬 Docker 개발 구조를 실제 고객이 사용할 수 있는 백엔드, PostgreSQL, 비공개 객체 저장소 구조로 이전한다.

## 2. 구현 범위

- 개발·스테이징·운영 환경과 비밀키 분리
- 관리형 또는 운영 서버 PostgreSQL 배포
- 사진·생성 이미지·출력 파일을 비공개 객체 저장소에 보관
- 인증 프록시 다운로드 또는 짧은 만료의 서명 URL 사용
- 저장 시 암호화, 전송 구간 TLS, 최소 권한 서비스 계정
- DB와 객체 저장소 백업·보존·복원·삭제 절차
- 개발 Mock 인증, 디버그 설정, 공개 CORS의 운영 비활성화
- 모니터링, 오류 경보, 감사 로그 보존과 개인정보 마스킹

## 3. 검증

- 스테이징에서 신규 가입부터 프로젝트·사진·생성·출력·다운로드까지 E2E
- 서명 URL 만료와 다른 워크스페이스 재사용 차단
- DB 복원과 객체 파일 연결 무결성 확인
- 키 교체, 장애 복구, 사용자 탈퇴·워크스페이스 삭제 훈련

## 4. 완료 기준

- 운영 환경에 로컬 파일 저장 또는 공개 버킷이 없다.
- 백업 복원 목표와 실제 복원 결과가 문서화된다.
- Critical/High 보안 항목 없이 배포 체크리스트를 통과한다.
- 이 Sprint 완료 전에는 실제 결제와 외부 고객 베타를 열지 않는다.
