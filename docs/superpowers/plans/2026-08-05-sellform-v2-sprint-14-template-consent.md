# Sellform V2 Sprint 14 — 공개 템플릿 동의·비식별화

상태: 구현 계획  
선행 조건: Sprint 13  
후속 Sprint: Sprint 15 운영 배포 준비

## 1. 목표

기본값은 비공개로 유지하고, 사용자가 명시적으로 동의한 자료만 비식별화와 별도 승인을 거쳐 공개 템플릿 라이브러리에 등록한다.

## 2. 데이터 모델

- 동의한 사용자·워크스페이스·원본 버전
- 동의 범위와 동의 시각·정책 버전
- 철회 시각과 처리 상태
- 비식별화 검수 상태·검수자·승인 시각
- 원본과 분리된 템플릿 복제본

## 3. 처리 절차

1. 사용자가 공개 제공 범위와 예시를 확인하고 명시적으로 동의한다.
2. 상품명, 개인정보, 주문 정보, 로고, 사진과 고유 식별 정보를 제거한다.
3. 자동 검사 후 운영자가 복제본만 검수한다.
4. 승인된 복제본만 템플릿 라이브러리에 게시한다.
5. 동의 철회 시 신규 사용을 중단하고 정책에 따라 게시물을 회수한다.

## 4. 완료 기준

- 미동의 자료가 템플릿 후보 조회에도 나타나지 않는다.
- 동의·비식별화·승인 중 하나라도 없으면 게시할 수 없다.
- 운영자가 원본 프로젝트를 템플릿으로 직접 지정할 수 없다.
- 동의 철회와 감사 이력이 검증된다.
