# Sprint 2 — 이미지 자산 이해: 역할·품질·OCR

## 목표

업로드된 상세 이미지가 어떤 섹션에 적합한지 자동 제안하고, 판매자가 쉽게 바로잡는다.

## 범위

- 역할 분류: 대표 제품컷, 기능, 사용 장면, 구성품, 디테일, 스펙, 배너/기타
- 해상도·비율·중복·제품 식별 가능 여부 검사
- OCR로 이미지 안의 수치/구성품/주의사항 후보 추출
- 자산 보드에서 역할, 품질, OCR, 현재 사용 섹션 표시

## 완료 기준

- 하나의 사진이 여러 본문 섹션에 자동 반복 배치되지 않는다.
- 저화질 HERO와 텍스트가 너무 많은 배너는 경고한다.
- 판매자가 역할을 직접 변경하면 이후 스토리보드에 반영된다.
