# Sprint 0 — 쿠팡형 상세페이지 기준선과 평가 기준

## 목표

“좋아 보이는가”가 아닌 공통 기준으로 결과를 판단할 수 있게 기준 상품, 참고 상세페이지 구조, 평가표를 고정한다.

## 범위

- 소형 가전·뷰티·생활용품 기준 상품 3종 선정
- 상품별 원본 이미지 묶음, 확인된 스펙, 참고 상세페이지 캡처 등록
- HERO/기능/사용 장면/구성품/스펙/CTA 평가표 정의
- 현재 결과를 기준선 JPG로 보관

## 완료 기준

- 각 상품에 최소 대표컷 1장, 기능/상세 이미지 3장 이상을 확보한다.
- 이미지 반복, 근거 없는 주장, 빈 섹션, 출력 불일치 항목을 평가표에 포함한다.
- 이후 Sprint가 같은 3개 상품을 회귀 테스트에 사용한다.
