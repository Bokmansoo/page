# Sprint 1 — 상품 자료 묶음 입력

## 목표

상품명과 숫자 몇 개가 아니라, 쿠팡형 상세페이지를 조립할 수 있는 **상품 자료 묶음**을 판매자로부터 받는다.

## 범위

- 다중 이미지 드래그앤드롭/일괄 업로드
- 상품명, 카테고리, 가격, 배송, 상세 설명, 기능·구성품·주의사항 입력
- 숫자+단위 입력 보존 및 확인 화면 제공
- 링크 수집 실패(403 등)를 안내하고 이미지 업로드 대안을 제공

## 제외

- 외부 사이트 접근 제한을 우회하는 수집

## 완료 기준

- 판매자가 5장 이상 이미지를 한 번에 올리고 순서를 확인할 수 있다.
- `260g`, `10분`, `800mAh`가 요약/확인/저장 어느 단계에서도 변형되지 않는다.
- 이미지가 부족하면 필요한 이미지 유형을 구체적으로 안내한다.
