# Sprint 4 — 쿠팡형 스토리보드 플래너

## 목표

이미지와 사실을 단순 나열하지 않고, 구매 설득 흐름에 맞는 섹션 계획으로 조립한다.

## 범위

- `commerce_story` 템플릿의 6~10개 섹션 계획 생성
- 섹션마다 목적, 제목, 근거 사실, 후보 이미지, 레이아웃, 대체 규칙 지정
- 대표컷은 HERO, 기능컷은 각 기능 섹션, 구성품/스펙 이미지는 해당 섹션에 우선 배치
- 동일 이미지 반복 방지와 최소 이미지 간격 규칙
- 스토리보드 승인 전 미리보기

## 완료 기준

- 최소 4개 역할의 이미지가 있으면 서로 다른 본문 섹션에 배치된다.
- 자료 부족 섹션은 임의의 장점 카드가 아니라 판매자 보완 요청 또는 안전한 정보 그래픽으로 표시된다.
- 판매자가 이미지 후보와 섹션 순서를 승인한 뒤에만 최종 페이지를 조립한다.
