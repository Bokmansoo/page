# Sprint 3 — 상품 사실 보드와 증거 연결

## 목표

상세페이지의 모든 판매 주장이 이미지 OCR, 판매자 입력 또는 승인된 출처에 연결되게 한다.

## 범위

- 사실 유형: 수치, 기능, 구성품, 사용 방법, 주의사항, 가격/배송
- 각 사실에 출처 이미지/원문/확인 상태 저장
- OCR 후보와 판매자 직접 입력의 병합·중복 제거
- 불확실한 효능/과장 문구의 검수 상태 처리

## 완료 기준

- 스펙 표와 수치 강조는 `confirmed` 사실만 사용한다.
- 판매자가 사실을 확인/수정/제외할 수 있다.
- 이미지 속 문구를 OCR로 읽지 못해도 원본 이미지를 근거로 확인 요청할 수 있다.
