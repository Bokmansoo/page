# Sprint 5 — `commerce_story` 상세페이지 렌더러

## 목표

승인된 스토리보드를 모바일 우선의 긴 세로형 판매 상세페이지로 렌더한다.

## 범위

- HERO: 대표 이미지, 핵심 카피, 주요 수치
- 기능 섹션: 각기 다른 제품/디테일 이미지와 근거 문구
- 사용 장면·구성품·스펙·주의사항·CTA 레이아웃
- 이미지 중심 레이아웃과 사실 기반 HTML 그래픽의 조합
- 모든 섹션의 이미지 비율, 가독성, 긴 한글 문구 처리

## 완료 기준

- 단일 사진 반복 없이 6개 이상의 읽기 흐름이 완성된다.
- 본문 이미지/그래픽/텍스트가 섹션 목적에 맞게 구분된다.
- 자료가 충분한 기준 상품에서 카드만 있는 페이지가 아니라 이미지 중심 판매 페이지가 생성된다.
