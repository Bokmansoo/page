# 쿠팡형 상세페이지 V1 문서 보관소

상태: **이전 버전·참고 전용**  
보관일: 2026-08-01

## 현재 구현 기준

이 폴더의 문서는 초기 쿠팡형 상세페이지 방향과 당시 구현·검증 이력을 보존하기 위한 자료다. 새로운 구현 기준으로 사용하지 않는다.

현재 제품·기술 기준은 다음 문서를 따른다.

- [Sellform Commerce Studio V2 최종 기획서](../../superpowers/plans/2026-08-01-sellform-commerce-studio-v2-final-master-plan.md)
- [Sellform V2 Sprint 0 기획서](../../superpowers/plans/2026-08-01-sellform-v2-sprint-0-baseline-and-policy.md)

## 보관 내용

- `plans/`: 쿠팡형 V1 전체 기획 및 Sprint 0~8
- `reviews/`: V1 Sprint 0~1 구현 코드리뷰
- `testing/`: V1 기준선 테스트 증거

## 사용 규칙

- 기존 코드의 구현 배경과 이전 판단을 추적할 때만 참고한다.
- V2 기획과 충돌하면 V2 문서를 우선한다.
- 이 문서의 완료 표시는 V2 완료를 의미하지 않는다.
- 실행 코드와 자동 테스트는 이 보관 작업의 대상이 아니며 기존 위치에 유지한다.
