# 경추 마사지 베개 상품 입력 예시

아래 내용을 새 프로젝트의 상품 정보 입력란에 그대로 복사해 사용할 수 있습니다.

## 상품 기본 정보

- 상품명: 경추 마사지 베개 / 온열 압박 마사지기
- 모델명: YL-T02
- 색상: 그레이
- 권장 사용 연령: 만 18세 이상
- 카테고리: 리빙 · 소형 가전
- 판매 채널: 네이버 스마트스토어

## 상품 사양

- 정격 입력: DC 5V 2A
- 정격 주파수: 50/60Hz
- 정격 소비전력: 8W
- 권장 작동 시간: 10분
- 배터리 용량: 2000mAh
- 제품 크기: 40 × 17 × 15cm
- 외부 포장 크기: 53 × 41.5 × 32cm
- 외부 포장 구성: 6개입

## 상품 상세 설명

목과 어깨 주변에 편안하게 밀착되는 베개형 마사지기입니다.

DC 5V 2A 입력과 8W 정격 소비전력 기준으로 작동하며, 한 번 사용할 때 약 10분 사용을 권장합니다.

2000mAh 배터리를 적용했으며, 제품 크기는 약 40 × 17 × 15cm입니다.

구매 전 모델명(YL-T02), 색상, 구성품 및 사용 방법을 확인해 주세요.

## 입력 시 참고

- `외부 포장 크기`와 `외부 포장 구성`은 제품 자체 사양과 구분해 입력합니다.
- 구성품이 확정되었다면 `구성품: 본체, 충전 케이블, 사용 설명서`처럼 별도로 추가합니다.
- KC 인증, 의료 효과, 통증 완화, 무상 A/S 등은 확인 근거가 없으면 입력하지 않습니다.
